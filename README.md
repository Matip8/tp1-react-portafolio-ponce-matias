## Alumno

## Descripción

Portfolio personal desarrollado como Trabajo Práctico N.º 1 de Programación IV.

El proyecto presenta información sobre mi perfil como desarrollador Junior Full Stack en formación, mis habilidades, proyectos realizados y medios de contacto.

La aplicación fue desarrollada utilizando React y Vite, aplicando conceptos como componentes, props, arrays, map(), eventos, estado con useState y renderizado condicional.

## Tecnologías utilizadas

- React
- Vite
- JavaScript
- JSX
- CSS
- Git
- GitHub

## Instalación

Para instalar las dependencias del proyecto:

```bash
npm install
```

## Ejecutar el proyecto

Para iniciar el proyecto de forma local:

```bash
npm run dev
```

Luego, abrir en el navegador la dirección indicada por Vite, normalmente:

```text
http://localhost:5173/
```

## Funcionalidades

- Portfolio desarrollado con componentes de React.
- Navegación entre secciones.
- Sección de presentación personal.
- Listado dinámico de habilidades.
- Listado dinámico de proyectos.
- Uso de props entre componentes.
- Estado con useState.
- Evento onClick.
- Renderizado condicional.
- Diseño responsive.
- Fondo animado estilo Matrix.
- Enlaces de contacto y GitHub.
